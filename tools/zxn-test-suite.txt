# Curated Rift programs that must execute to completion in the ZXN test
# profile.  `tools/test-zxn` compiles each through `rift --target=zxn
# --zxn-test` and validates its debug-port result stream through ZEsarUX.
#
# Keep this focused on portable semantic coverage.  Hardware interaction is
# smoke-tested (keyboard and plot), not asserted against a user-controlled
# physical device state.
test/simple_test.rift       # baseline compiler/runtime path
test/byte_test.rift         # conversions, arithmetic, dynamic byte arrays
test/concat_test.rift       # string concatenation and char conversion
test/array_test.rift        # dynamic/fixed arrays, records and returns
test/format_test.rift       # function arguments and formatted strings
test/keyboard_test.rift     # keyboard builtin/link path and bounds handling
test/plot_test.rift         # ULA pixel drawing and clipping smoke
test/clock_test.rift        # ROM FRAMES clock and fixed-point trig
test/zxn-probes/paper_cls_probe.rift # paper sysvar and full ULA clear
